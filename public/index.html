欢迎使用双层 Agent 自迭代系统

三步跑起来；已就绪的项目会自动跳过本向导
1 安装外层引擎 OpenCode
命令行执行：
npm install -g opencode-ai
登录配置模型：opencode auth login
2 配置内层 LLM（OpenAI 兼容 API）
填写 base_url / api_key / model，密钥仅保存在本机。
3 或者先体验演示模式
不装任何东西也能跑通全流程（假 LLM + 假 opencode）：
DUAL_AGENT_MOCK=1 node server.js
